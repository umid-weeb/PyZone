# Project at a glance

- **Name:** PyZone
- **Purpose:** Web-based Python editor and coding-challenge arena
- **Audience:** Students, learners, and interview prep users
- **Core modules:** Frontend Arena app, FastAPI backend, judge/submission pipeline
- **Operational readiness:** CI workflow, contribution templates, and secret scanning skeleton
- **Security posture:** `.env` files ignored, sanitized `.env.example`, and key-rotation guidance required when leaks are found
